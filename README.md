## ✨ Features

- **Modern Glassmorphism UI**: High-refraction frosted glass login card with `backdrop-filter: blur(28px)`, multi-layer depth shadows, and specular edge reflections.
- **Top-Left Minimalist Branding**: Pure circular emblem with leaf & AI neural node vector graphic and **EcoScan AI** title. Zero phone/email clutter.
- **Pure CSS Falling Leaves Simulation**: Multi-layered physics animation with 4 realistic autumn leaf silhouettes (Maple, Oak, Birch, Elm) falling across the scenic background.
- **Interactive Campus Portal**:
  - Sign In / Sign Up tab switching.
  - Interactive password visibility toggle.
  - Live cluster node status (`Cluster: North Campus Station ● Online`) with telemetry routing.
  - Form validation with loading feedback and glass toast notifications.
- **Clean Layout**: No bottom control bars, simulators, or seek bars.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kumarsachin1240421-code/CHE-110.git
   ```
2. Open `index.html` directly in any web browser, or serve it with Python:
   ```bash
   python -m http.server 8088
   ```
3. Visit `http://localhost:8088` in your browser.
